# Support — Stop Ahead (English)

## An alert did not arrive

1. Open **Settings > Alert status** in the app. It lists what can stop an alert and each problem has a button that opens the right system page.
2. Location must be set to **Always** and **Precise**. Without it the phone cannot wake the app when you reach a place.
3. Notifications must be on for Stop Ahead.
4. Android only: set the battery use of Stop Ahead to **Unrestricted** (on Samsung phones, remove it from "Sleeping apps" and "Deep sleeping apps"). Some phones stop apps in the background to save battery.
5. Tap **Send a test alert** on the same screen. If the notification arrives, the path works; if it does not, the status screen tells you why.
6. Check that the place is switched on in **Places** and that the alert distance is large enough for how you travel (fast trains need more distance).

Quiet hours, a pause and a place schedule also silence alerts on purpose; **History** shows every alert the app chose not to send and why.

## Send a report

In **Settings > Help and support** choose **Share a report**. The app saves a small technical file where you choose; attach it to an email to us. It contains the app version, the phone model and system version and what the app did, never place names or coordinates. The app never uploads it.

## Your data

- **Settings > Back up your data** saves your places to a file you keep.
- **Settings > Privacy > Delete all my data** removes everything from the phone.
- Nothing is stored on a server: there is no account.
